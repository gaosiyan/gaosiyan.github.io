# 什么是 QEMU

**QEMU**(Quick Emulator)是一款免费开源模拟器(Emulator),由法布里斯·贝拉(Fabrice Bellard)等人编写.其与 Bochs 类似.它使用动态二进制转换来模拟计算机的处理器;也就是说,它将模拟的二进制代码转换为由机器执行的等效二进制格式.它为虚拟机提供了多种硬件和设备模型,使其能够运行不同的来宾作系统.QEMU 可以与基于内核的虚拟机 (KVM) 一起使用,以接近本机的速度模拟硬件.此外,它还支持用户级进程,允许为一种处理器架构编译的应用程序在另一种处理器架构上运行.

QEMU 支持 x86,ARM,PowerPC,RISC-V 和等架构的仿真.
