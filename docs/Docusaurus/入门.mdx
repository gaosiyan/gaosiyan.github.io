# Docusaurus 简介

Docusaurus 是由 Meta(原 Facebook)开源的现代化静态网站生成框架,基于 React 构建,专为技术文档,博客和内容型网站设计.
Docusaurus 于 2017 年首次发布,当前(2025/08/09)的最新的版本是 Docusaurus 3.8.1.

核心特性:

- 静态生成与动态交互结合:生成高性能静态 HTML,同时支持 SPA(Single-Page Application,单页应用)的客户端导航与动态交互;
- MDX 深度集成:支持在 Markdown 文档中直接嵌入 React 组件,实现样式定制与交互功能增强;
- 多平台部署支持:提供一键部署至 GitHub Pages,Vercel,Netlify 等平台的能力.

官方资源:

- [Docusaurus 官网](https://www.docusaurus.cn/ "访问 Docusaurus 官方网站")

# 使用 Docusaurus 创建本地站点

:::tip
前置条件: 已经安装 `Node.js`.
:::

1. 使用如下官方提供的命令创建模板站点:

   ```bash
   npx create-docusaurus@latest my-website classic
   ```

   上面的命令将会在当前目录下创建 `my-website` 目录用于保存站点的所有文件.

   执行后如下 <FigureRef id="创建本地站点" /> 所示建议选择 TypeScript:

   <Figure
     src="/img/content/bd776b573f4c3e554c98f2e6b8b3c6101c8c1a42.png"

   :::tip
   默认使用 JavaScript. 也可以使用下面的命令跳过语言配置,直接使用 TypeScript:

   ```bash
   npx create-docusaurus@latest my-website classic --typescript
   ```

   :::

## Front Matter 元数据

Front Matter 元数据是 Markdown 文档顶部的 YAML 格式数据,例如:

```yaml
---
id: my-doc-id
title: My document title
description: My document description
slug: /my-custom-url
---
```

位于 Markdown 文档顶部,并且用`---`包裹,其中元素都是变量,以当前文档为例:

```yaml
sidebar_position: 1
sidebar_label: "入门"
```

其中:

- `sidebar_position` 表示文档位置;
- `sidebar_label` 表示显示的标题,不一定和文档名相同.

另外每个目录下有 `_category_.json` 文件,以当前目录为例:

```json
{
  "position": 1,
  "label": "docusaurus"
}
```

其中:

- `position` 表示当前目录的位置;
- `label` 表示当前目录的名称.
