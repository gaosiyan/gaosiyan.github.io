table 库

```bash
npm install @tanstack/react-table
```

数学公式库,需要修改配置文件和 CCS

```bash
npm install --save remark-math@6 rehype-katex@7
```

配置本地搜索

```bash
npm install @easyops-cn/docusaurus-search-local @docusaurus/types
```

markdown 扩展
```bash
npm install remark-gfm
```

Discussions 新建 Discussions Github 仓库

```
npm install @giscus/react
```
已在仓库中启用 GitHub Discussions(仓库 Settings → Features → 勾选 Discussions)

1. 本地安装插件;
2. GitHub 创建仓库,公开 (仓库 Settings → Features → 勾选 Discussions);
3. https://giscus.app/zh-CN 中配置,记录配置的信息;
4. 根据配置的信息,创建组件,将对应的组件加入到文档最后.
