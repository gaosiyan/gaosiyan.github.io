table 库

```bash
npm install @tanstack/react-table
```

数学公式库,需要修改配置文件和 CCS

```bash
npm install --save remark-math@6 rehype-katex@7
```

本地搜索

```bash
npm install @easyops-cn/docusaurus-search-local @docusaurus/types
```

markdown 扩展
```bash
npm install remark-gfm
```
