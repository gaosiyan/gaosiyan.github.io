FDD-TDD HARQ-ACK 反馈机制遵循条款 7.3.2.2 所述的 HARQ-ACK 流程,但存在以下例外:

  • 对于帧结构类型 1 的服务小区,且 UE 未配置为在其他服务小区中监控 PDCCH/EPDCCH 以调度该服务小区时,KKK 由 Table 10.1.3A-1 定义;否则 KKK 由 Table 10.1.3.1-1 定义.

  • 对于帧结构类型 1 的服务小区,且 UE 未配置为在其他服务小区中监控 PDCCH/EPDCCH 以调度该服务小区时,若 Table 10.1.3A-1 中该服务小区的 DL-reference UL/DL configuration 属于 {2,3,4},则 BcDLB_c^{DL}BcDL​ 按条款 7.3.2.2 中 DL-reference UL/DL configuration 为 {5} 的服务小区方式确定.

  • 对于帧结构类型 1 的服务小区,若配置 PUCCH format 3 用于传输 HARQ-ACK,且对于基于检测到 DCI format 0/4 的 PDCCH/EPDCCH 调整的子帧 nnn 中的 PUSCH 传输,UE 应假设该服务小区的 UL-reference UL/DL configuration 属于 {1,2,3,4,5,6}.

  • 对于帧结构类型 1 的服务小区,若各服务小区的 DL-reference UL/DL configuration 均属于 {0,1,2,3,4,6},且配置带信道选择的 PUCCH format 1b 用于传输 HARQ-ACK 并有两个已配置服务小区时,UE 应假设该服务小区的 UL-reference UL/DL configuration 属于 {1,2,3,4,6}.

  • 对于帧结构类型 1 的服务小区,WDAIULW_{DAI}^{UL}WDAIUL​ 值由子帧 n−k′n - k'n−k′ (其中 k′=4k' = 4k′=4) 中与该服务小区上 PUSCH 对应的 DCI format 0/4 内的下行分配索引(DAI)根据 Table 7.3-Z 确定.
