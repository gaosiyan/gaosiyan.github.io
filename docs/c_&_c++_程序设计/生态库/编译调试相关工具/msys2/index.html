MSYS2

MSYS2 简介​

MSYS2 是一套基于开源软件的工具和库集合,旨在为 Windows 提供原生构建环境.它集成了 Pacman 包管理器,支持 GCC,Clang 等主流开源构建工具,让用户能够在 Windows 上便捷地开发和构建软件.

MSYS2 在 Windws 上提供了 WIndows API->POSIX API 的转换,实现 Linux POSIX 软件运行,并包含了相关 Linux 工具.

MSYS2 带有不同的环境.所以最重要的事情是使用那个环境.环境之间的差异主要是:

  • 环境变量;
  • 编译器/连接器;
  • 架构;
  • 使用的系统库.

关于 的说明:

  1. 最后两个是 32 位环境已经不再推荐使用;
  2. MSYS 环境(/usr)中包含基于 unix/cygwin 的工具,它始终处于活动状态($PATH).所有其他环境从 MSYS 环境继承并在其上添加各种内容;
  3. MSYS2 官方建议最好选择最新的 UCRT64,例如启动 ucrt64.exe,可以使用 UCRT64 和 MSYS2 中的工具,此时搜索路径为 $PATH/ucrt64/bin:/usr/bin;
  4. MSVCRT 和 UCRT 是 Microsoft Windows 上 C 标准库的两种变体.
  • MSVCRT (Microsoft Visual C++ Runtime) 在所有 Microsoft Windows 版本,但由于向后兼容性问题不兼容 C99,并且缺少一些功能;
  • UCRT(Universal C Runtime,通用 C 运行时)是一个较新的版本,Visual Studio 2015 以及以后的版本默认使用 UCRT 为 C 运行时.

Pacman 常用操作​

Pacman 是一个软件包管理器,作为 ArchLinux 发行版的一部分,是 Arch Linux 的一大亮点.后来被 MSYS2 引入.命令后面加 --noconfirm 表示无需确认默认执行:

pacman -Qs # 查看已安装软件,初始安装包全部在 local 下
pacman -S 包名_1 包名_2 ...  # 安装指定的软件包
pacman -S 仓库名/包名        # 有时软件包有多个版本,放在不同的仓库内,这里指定安装对应仓库的包

有一些软件包含多个软件包,称为一个软件包组,比如用下面的命令安装 mingw-w64-ucrt-x86_64-toolchain

pacman -S mingw-w64-ucrt-x86_64-toolchain

会安装 19 个软件包.安装完成后,可以用下面的命令查看那些包属于 mingw-w64-ucrt-x86_64-toolchain 软件包组

pacman -Sg mingw-w64-ucrt-x86_64-toolchain

卸载一定特别注意依赖关系.防止递归卸载.

pacman -Rsc mingw-w64-ucrt-x86_64-toolchain

上面的命令用于卸载mingw-w64-ucrt-x86_64-toolchain 软件包及其相关依赖,并清理这些包的配置文件和缓存.以下是命令参数的具体含义:

  • -R :表示卸载(移除)指定的软件包;
  • -s :表示同时移除那些不再被其他已安装软件包所需的依赖包;
  • -c :表示清理配置文件,移除与该软件包相关的配置文件.
  • mingw-w64-ucrt-x86_64-toolchain :这是要卸载的软件包名称,它是一个工具链包,包含了用于在 MSYS2 的 UCRT64 环境下编译 64 位 Windows 应用程序所需的编译器和工具,例如 GCC,GDB,Make 等.

Pacman 缓存位于 /var/cache/pacman/pkg/ 不会自动移除旧的和未安装的软件包,需要定期手动清理

pacman -Sc --noconfirm # 清理未安装的软件包文件,--noconfirm 无需确认
pacman -Scc--noconfirm # 清理所有的缓存文件

升级包

pacman -Sy --noconfirm  # 从服务器更新软件包数据库
pacman -Syu --noconfirm # 一个 pacman 命令就可以升级整个系统

相关库安装​

pacman -Syu # 更新系统
pacman -S mingw-w64-ucrt-x86_64-toolchain # 安装 gcc 工具链,还是只能编译 64 为,32 位的要另安装
pacman -S mingw-w64-ucrt-x86_64-cmake # 安装 cmake
pacman -Scc # 清理所有的缓存文件
提示

mingw-w64-ucrt-x86_64-toolchain 安装完成后需要把安装目录ucrt64\bin 下的mingw32-make.exe复制一个,并修改成make.exe,原因是很多脚本调用的是 make 程序,而不是 mingw32-make 程序.
